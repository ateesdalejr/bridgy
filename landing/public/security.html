Security

Session files are secrets.

Bridgy isolates users by SMS phone number, verifies signed SMS webhooks, and keeps WhatsApp session files out of git.

Security Basics

  • Quo/OpenPhone webhooks are checked with the configured signing key.
  • Each SMS number has separate WhatsApp session storage.
  • Local `.env`, tunnel credentials, SQLite data, and WhatsApp auth files are ignored by git.
  • The setup UI links to source, privacy, security, status, and the running version label.

Report A Vulnerability

Email security@bridgy.chat. Please do not open public GitHub issues for vulnerabilities.

The full security policy is in SECURITY.md.
